# LoRA Stack Pro

ComfyUI 的 LoRA 堆节点。把「一层层翻文件夹找 LoRA、来回切标签页调权重」这件事搬进节点面板——浏览、选中、调权重、排顺序都在节点里完成。

## 功能

**目录浏览**
按 `models/loras` 的实际结构逐层展开，面包屑可回溯，只有一个子文件夹时自动进去，不用一路点。ComfyUI 里配置的额外模型路径（`extra_model_paths.yaml`）会一起纳入。

**跨层搜索**
搜索范围是全库，不限当前目录。空格分词取交集，`女仆装 像素` 找同时沾这两样的条目。搜索框右侧三个按钮：

- **范围**：循环切换 全部 → 文件夹 → LoRA。选「文件夹」时只返回命中的文件夹，点进去自己翻，避免一次铺出几百张卡片
- **标签**：默认关闭。开启后会匹配 LoRA 的训练标签，适合按画风或属性捞东西，代价是命中量会大很多
- **清空**：清掉搜索词回到目录浏览

工具栏右侧可切换排序（名称 / 修改时间 / 文件大小）和筛选（全部 / 只看无封面 / 只看重名）。刚下载的 LoRA 用「修改时间」一按就到顶。

**预览图**
自动从 LoRA 同目录的图片里识别预览图。缩略图按需生成 WebP 缓存，不会把几 MB 的原图直接塞给浏览器。`Pillow` 没装时退回原图，功能不受影响。

**Civitai 信息**
按文件哈希查询模型名、版本、底模、触发词、样例图，查询结果写在 LoRA 同目录，下次直接用。顶栏的下箭头打开批量补全面板，可按「只补无封面 / 跳过已有信息 / 顺带下载封面」筛选，设好单次上限和每项间隔后在后台跑。关掉面板、刷新页面都不会中断，重新打开接着显示进度，停下再点一次就继续。

**堆管理**
点卡片加入或移出，卡右上角 ✓ 表示已在堆中。底部「已选」区可拖拽排序。每行左侧 `−` / `+` 调权重，步进在设置里可改（0.01 / 0.05 / 0.1 / 0.2）。带 CLIP 的节点上模型与 CLIP 两个权重是联动的。单项可启停，可以收藏单个 LoRA，也可以把一整套搭配存成预设。

**封面**
详情里列出全部候选图，点选任意一张设为封面。没有本地图时，点占位框才去 Civitai 查并展开候选（最多 8 张，有几张显示几张）。选定的封面存成 `<lora文件名>.preview.<扩展名>`，正好落在预览图识别的「同名派生」规则上，所以就算封面记录丢了也能自动认回来。

**备注**
双击条目名字就地写备注，只改显示，不动文件名，备注也会参与搜索。

## 安装

放进 `ComfyUI/custom_nodes/`：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/CSQBZX/ComfyUI-LoraStack-Pro.git
```

或者下载 zip 解压到 `custom_nodes/ComfyUI-LoraStack-Pro`。

然后**重启 ComfyUI 进程**。只刷新页面不够——节点定义和 `/lora_stack_pro/*` 接口都在启动时注册，必须重启。

**依赖**

- `requests`、`aiohttp` —— ComfyUI 自带，不用管
- `Pillow` —— 可选，用于生成缩略图。没装就直接返回原图

除此之外没有别的依赖，也不需要 npm 或任何构建步骤。

**验证装好了**

重启后在节点列表里搜 `lora stack`，`loaders/lora` 分类下应该有两个节点：

| 节点 | 说明 |
| --- | --- |
| LoRA Stack Pro | MODEL + CLIP 进，MODEL + CLIP 出 |
| LoRA Stack Pro (Model Only) | 只输出 MODEL，省一条 CLIP 连线 |

**数据存在哪**

运行时产生的数据都落在插件目录下的 `data/`，该目录已加入 `.gitignore`，不会误提交：

```
data/
  hash_cache.json     全库 LoRA 的 sha256
  tag_cache.json      训练标签索引
  civitai/            按哈希查回的模型信息
  thumbs/             WebP 缩略图缓存，可随时删除，会重建
  aliases.json        别名
  covers.json         封面选择
  usage.json          使用频次
  presets.json        预设
```

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索框 |
| `↑` `↓` | 浏览区移动游标 |
| `Enter` | 加入 / 移出当前游标项 |
| `Shift` + `↑` `↓` | 堆内移动游标 |
| `-` `=` | 调权重 |
| `x` | 启用 / 停用当前项 |
| `Esc` | 逐层退出 |

## 已知限制

- **中文只能按字面搜**：没有拼音转换，搜「女仆装」找得到，搜 `nvpuzhuang` 找不到
- **触发词不做输出端口**：Civitai 的 `trainedWords` 混着训练集高频标签，多层合并会把几十个无关词塞进提示词，污染画面。触发词只在详情里查看、点击复制
- **重名文件**：本节点按完整相对路径区分不会选错，但生态里只认文件名的节点可能有歧义
- **Civitai 匿名限流**：批量补全建议每项间隔 1.2 秒以上，连续失败会提前停
- **改了 `nodes.py` 后要 `Ctrl+F5`**：ComfyUI 前端把 `/api/object_info` 缓存在内存里，不硬刷新的话画布上还是旧的输出端口
- **权重缓存吃内存**：默认上限 3 GB，可用环境变量 `LORA_STACK_PRO_CACHE_MB` 覆盖，单位 MB，设为 `0` 退回单条缓存

## 说明

这个插件是我自己用的时候嫌麻烦，让 AI 写出来给自己用的，不是什么正经项目，代码里大概还有不少没打磨的地方。

后来想想既然能跑，就顺手放出来了，万一正好也能帮到别人。所以如果你遇到问题——功能不符合预期、界面丑、边界情况没处理、跟某个自定义节点打架——都很正常，我大概率也没考虑过。

愿意提 issue 我很感激，但请别抱太高期待，我会看，不一定改得动。用不顺手的话，ComfyUI 生态里比我这个成熟的选择很多，换一个完全没问题。
