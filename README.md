# LoRA Stack Pro

ComfyUI 里用来管理和使用 LoRA 的节点。把「一层层翻文件夹找 LoRA」这件事直接做进节点面板——选中、调权重、排顺序都在节点里完成，不用来回切标签页。

## 功能

- **逐层浏览** `models/loras` 目录，面包屑跳转，只有一个子文件夹时自动进去
- **跨层搜索**：一次搜完全部子文件夹，同时匹配文件名、文件夹名和训练标签，空格分词取交集
- **中英同义词**：搜 `女仆装` 会一起搜 `maid`、`maid outfit`；搜 `像素` 会一起搜 `pixel art`
- **拼音搜索**：`nvpuzhuang` 或首字母 `npz` 都能命中中文文件夹名
- **预览图**：自动从 LoRA 同目录认出预览图，按需缩成 WebP 缓存，不把几 MB 的原图塞给浏览器
- **Civitai 信息**：按文件哈希查模型名、版本、底模、触发词、样例图，查过的数据存在 LoRA 旁边
- **堆管理**：点卡片加入/移出、拖拽排序、模型与 CLIP 双权重、单项启停、收藏、整套预设
- **键盘操作**：`/` 搜索、`↑↓` 浏览、`Enter` 加入、`-`/`=` 调权重，手不用离开键盘

## 安装

放进 `ComfyUI/custom_nodes/` 就行：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/CSQBZX/ComfyUI-LoraStack-Pro.git
```

或者下载 zip 解压到 `custom_nodes/ComfyUI-LoraStack-Pro`。

然后**重启 ComfyUI**（要重启进程，只刷新页面不够，节点定义和接口都在启动时注册）。

**依赖**

- `requests`、`aiohttp` —— ComfyUI 自带，不用管
- `Pillow` —— 可选，用来生成缩略图。没装就直接返回原图，功能不受影响
- `pypinyin` —— 可选，只用于拼音搜索。没装时静默降级，其它功能照常。要装：

```bash
<你的 python> -m pip install pypinyin
```

## 使用

节点在 `loaders/lora` 分类下，搜 `lora stack` 能找到两个：

| 节点 | 说明 |
| --- | --- |
| LoRA Stack Pro | MODEL + CLIP 进，MODEL + CLIP 出 |
| LoRA Stack Pro (Model Only) | 只输出 MODEL，省一条 CLIP 连线 |

**浏览与搜索**

面板默认折叠成一个普通 LoRA 堆，点「浏览 LoRA」展开。

搜索框输入即搜，范围是**全库**，不限当前文件夹。空格分词是「与」关系，比如 `女仆装 像素` 会找同时沾这两个的条目。搜索框右边的「标签」按钮可以关掉训练标签匹配，只按名字搜。

工具栏右侧能切排序（名称 / 修改时间 / 文件大小）和筛选（全部 / 只看无封面 / 只看重名）。刚落地的 LoRA 用「修改时间」一按就到顶。

**加入堆**

点任意卡片加入或移出，卡右上角的 ✓ 表示已在堆中。底部「已选」区可以拖拽调顺序。

每行左侧有一对 `−` / `+` 按钮调权重，步进在设置里可改（0.01 / 0.05 / 0.1 / 0.2）。带 CLIP 的节点上两个数字是同步的。

双击条目名字可以就地写备注——只改显示，不动文件名，备注也会参与搜索。

**封面**

有候选图时，详情里会列出全部候选，点选任意一张设为封面。没有本地图时，详情顶部是个占位框，点一下才去 Civitai 查并展开候选（最多 8 张，有几张显示几张）。

选好的封面会存成 `<lora文件名>.preview.<扩展名>`，正好落在预览图识别规则的「同名派生」上，所以就算封面表丢了也能自动认出来。

**快捷键**

| 按键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索框 |
| `↑` `↓` | 浏览区移动游标 |
| `Enter` | 加入 / 移出当前游标项 |
| `Shift` + `↑` `↓` | 堆内移动游标 |
| `-` `=` | 调权重 |
| `x` | 启用 / 停用当前项 |
| `Esc` | 逐层退出 |

**批量补全 Civitai 信息**

顶栏的下箭头按钮打开补全面板，能按「只补无封面 / 跳过已有信息 / 顺带下载封面」筛选，设好单次上限和每项间隔后后台跑。关掉面板、刷新页面都不影响，重新打开会接着显示进度。这批数据会写进 LoRA 同目录的 `.civitai.info`，随时停下再点一次就继续补。

**预设**

顶栏的书签按钮打开预设面板。它和「收藏」不是一回事：收藏是单个 LoRA 的集合，预设是**一整套搭配**——哪些 LoRA、各自多少权重、谁被停用了。可以保存、套用、覆盖、删除。

## 已知限制

- **拼音多音字**：只取默认读音。`银行` 取 `yinhang`，打 `yinxing` 搜不到
- **触发词不做输出端口**：Civitai 的 `trainedWords` 混着训练集高频标签，多层合并会把几十个无关词塞进提示词，污染画面。触发词只在详情里查看、点击复制
- **重名文件**：本节点按完整相对路径区分不会选错，但生态里只认文件名的节点可能有歧义
- **Civitai 匿名限流**：批量补全建议每项间隔 1.2 秒以上，连续失败会提前停
- **改了 `nodes.py` 后要 `Ctrl+F5`**：ComfyUI 前端把 `/api/object_info` 缓存在内存里，不硬刷新的话画布上还是旧的输出端口
- **权重缓存吃内存**：默认上限 3 GB，可用环境变量 `LORA_STACK_PRO_CACHE_MB` 覆盖
